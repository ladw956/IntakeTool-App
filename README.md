# IntakeTool — Educational Demo

**Try the hosted demo:** https://intaketool.onrender.com/

IntakeTool is an educational intake and project-registration application. This public repository is provided as an end-user guide for the hosted demo.

## Source availability

The IntakeTool source code is **not publicly available**.

This repository does not contain the application source and is not intended as an installation package. The application can be viewed and explored through the hosted Render demo.

## What you can explore

The demo lets you experience an intake/project workflow, including:

- account registration and login
- project creation and management
- client/project information
- intake questions and answers
- project status/workflow views
- dashboard and project overview features

## Getting started

1. Open https://intaketool.onrender.com/
2. Choose **Register** to create your own sandbox account.
3. Log in with the account you created.
4. Create or explore projects.
5. Start an intake and work through the available questions.
6. Explore the dashboard and project-management pages.

## Demo / sandbox notice

This is an educational portfolio demo, not a production service.

- Data can be changed or reset as the demo evolves.
- Do not enter real confidential or sensitive information.
- Do not reuse an important password when creating a demo account.
- Uploaded files may be temporary and can disappear after the hosted service restarts or redeploys.
- The demo may take a little while to open after being inactive because the free hosting instance can spin down.

## Hosting

The web application is hosted on Render. Its educational database is hosted separately on a private VPS and is accessed through a restricted TLS connection.
